# PulseNews - 맞춤형 뉴스 리더 📰

비즈니스, 스포츠, 문화 등 관심 있는 주제의 최신 헤드라인을 실시간으로 확인하는 맞춤형 뉴스 리더 웹 애플리케이션입니다.

## ✨ 주요 기능
- **다중 카테고리 필터링**: 비즈니스, 스포츠, 문화 주제를 자유롭게 다중 선택
- **실시간 OpenAPI 연동**: Google News RSS 기반 실시간 뉴스 헤드라인 수신 및 고품질 폴백 지원
- **반응형 카드 그리드**: 깔끔한 화이트 배경과 소프트 섀도우를 적용한 모던 UI
- **상세 본문 모달**: '읽기' 버튼을 클릭하여 기사 상세 본문 및 원문 링크 확인
- **무한 스크롤 (Infinite Scroll)**: 페이지 하단 도달 시 `IntersectionObserver`로 10건씩 자동 로드

## 🛠 기술 스택
- **HTML5** / **CSS3 (Modern Vanilla CSS)** / **JavaScript (ES6+)**
- **RSS-to-JSON API**

## 🚀 실행 방법
- 별도 설치 없이 `index.html` 파일을 브라우저에서 바로 열거나,
- Node.js 환경에서 `node server.js` 실행 후 `http://localhost:3000` 접속
